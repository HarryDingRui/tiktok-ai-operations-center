# 运营中控台云端数据文档

这是网站自动读取的主数据文件：`data/operations-data.json`。

## 更新方式

1. 在 GitHub 网页打开本文件，点击编辑。
2. 按现有字段结构替换真实数据；不要删除字段名。
3. 提交到 `main` 分支。
4. 等 GitHub Pages 发布完成后，刷新网站并点击“同步云端数据”。

## 数据分区

- `storeStats`：全部店铺和各店铺总览指标、成交来源占比。
- `products`：商品/链接、销量、GMV、GMV变化、CVR变化和店铺。
- `actions`：运营已执行动作、负责人、验证节点、证据和结论。
- `publishTrend`：每日自营发布量。
- `bd`：达人合作与交付汇总。
- `ads`：广告汇总和广告计划明细。
- `video`：自营短视频汇总。

## 口径要求

- 缺失数据使用 `null`，不要用 0 代替未知。
- GMV 使用数字字段，网站负责格式化金额。
- 百分比字段按“数值百分比”填写，例如 `3.86` 表示 `3.86%`。
- 运营动作的 `result` 只有在 T+1/T+3/T+7 有真实证据时才填写有效或无效，否则保持待验证。
- 本文件目前是演示模板，真实数据接入前请先确认授权、时间范围和字段口径。
