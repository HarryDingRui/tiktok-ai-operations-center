⚙️ 数据接入
Control Plane 数据源 · Agent 执行需要真实数据支撑 · 不以推算替代缺失
ℹ️文件只在本机浏览器内解析和保存，不会自动上传。正式网站部署前，需要主管确认数据源、账号权限、同步频率和敏感字段处理方式。
🧩 数据上传自适应 核心原则：中控台适应店铺数据，不要求固定模板
店铺后台能导出什么表，就直接上传什么表，不需要手工改成指定格式。系统会自动做四件事： ① 智能识别表头——中英文列名、同义写法、带单位/空格的列名都能认； ② 自动推断店铺和日期——优先读表内字段，其次读文件名，都读不到才会问你； ③ 粒度自适应——有什么字段算什么指标，缺字段的模块显示"待导入"，不会卡住其他模块； ④ 导入报告 + 映射记忆——每次导入生成报告（识别行数、匹配字段、未识别列），没认出的列手动指认一次，系统永久记住。
☁️ WPS / Kdocs 云文档 统一填报源 · 适配当前 v3 模块
运营先在云文档填写店铺、商品、五组排行、预警、运营动作、知识库和 Agent 任务；再按字段说明导出 CSV 或交给后端 API 接入。当前公开 GitHub Pages 仍是静态演示版，不会直接读取私有 WPS/Kdocs 文档。
